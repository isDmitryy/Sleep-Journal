Создай приложение "Sleep Journal" — личный трекер сна.

## Стек
React + Vite, Tailwind CSS, Recharts, date-fns, Framer Motion, localStorage

## Дизайн
Тёмная тема (глубокий тёмно-синий/фиолетовый фон, акценты — нежный синий и лавандовый).
Минималистичный, спокойный, визуально красивый UI.

## Страницы/разделы (SPA с роутингом через вкладки)

### 1. Dashboard (главная)
- Карточки: средняя продолжительность за неделю, средняя оценка качества, текущий streak (дней подряд с записью)
- График за последние 7 дней: столбцы — продолжительность сна, цвет — качество
- Последняя запись с кратким summary

### 2. Добавить запись
- Форма: дата, время отхода ко сну, время подъёма
- Ползунок качества сна (1–10) с emoji-индикатором
- Текстовое поле "Заметки" (необязательно)
- Автоматический расчёт продолжительности сна

### 3. История
- Список всех записей в виде карточек (дата, продолжительность, качество, заметки)
- Возможность удалить запись
- Фильтр по месяцу

### 4. Статистика
- График за последние 30 дней (Recharts LineChart — продолжительность + качество)
- Среднее время засыпания и подъёма
- Распределение качества сна (PieChart)

## Данные
Хранить в localStorage как массив JSON-объектов:
{ id, date, bedtime, waketime, duration, quality, notes }

## Прочее
- Адаптивная вёрстка (mobile-first)
- Плавные переходы между разделами (Framer Motion)
- Пустые состояния с мотивирующим текстом, если записей нет
